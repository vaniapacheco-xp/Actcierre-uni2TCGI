Bases de Datos Bibliográficas

⏱ 25 minutos 📖 Tema 2.3.1 📎 Evidencia: Fichas bibliográficas
▼
2.3.1 Bases de Datos Bibliográficas
📋 Instrucciones: Explorarás tres tipos de bases de datos bibliográficas: un catálogo de biblioteca, una base multidisciplinar y una especializada. En cada una realizarás una búsqueda real sobre tu tema y registrarás los resultados.

🔹 A) Catálogo bibliotecario en línea (OPAC)

Ingresa al catálogo de tu biblioteca universitaria o usa uno de estos:

  • 📗 Catálogo UNAM (IIB) 🔗
  • 📗 Catálogo COLMEX 🔗
  • 📗 WorldCat (catálogo mundial) 🔗

🔹 B) Base de datos multidisciplinar

Accede a una de estas bases (muchas universidades tienen acceso institucional):

  • 📘 Redalyc (acceso abierto) 🔗
  • 📘 Dialnet 🔗
  • 📘 SciELO 🔗
  • 📘 Scopus (requiere acceso) 🔗

🔹 C) Base de datos especializada por área

Según tu carrera, elige una base especializada:

  • 🏥 PubMed (Ciencias de la Salud) 🔗
  • 💻 IEEE Xplore (Ingeniería/Tecnología) 🔗
  • 🎓 ERIC (Educación) 🔗
  • 📜 JSTOR (Humanidades/Sociales) 🔗
  • 🔬 ScienceDirect (Ciencias) 🔗

⏱ 20 minutos 📖 Tema 2.3.2 📎 Evidencia: Datos estadísticos
▼
2.3.2 Bases de Datos Numéricas – INEGI
📋 Instrucciones: Las bases de datos numéricas contienen cifras, estadísticas e indicadores. El INEGI (Instituto Nacional de Estadística y Geografía) es la principal fuente de datos estadísticos de México. Buscarás datos concretos relacionados con tu tema o área de estudio.

🔹 Recursos INEGI

  • 📊 Portal principal INEGI 🔗
  • 📊 Buscador de indicadores 🔗
  • 📊 Cuéntame de México 🔗
  • 📊 Biblioteca digital INEGI 🔗

🔹 Parte A: Búsqueda de indicadores

Busca en INEGI un dato estadístico que se relacione con tu tema de investigación. Ejemplos: si tu tema es salud, busca número de hospitales; si es tecnología, busca hogares con internet; si es educación, busca tasa de escolaridad.
